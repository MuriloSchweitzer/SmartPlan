# SmartPlan

Projeto inicial da estrutura de monorepo para o SmartPlan.

## Estrutura

```
SmartPlan/
├── backend/
│   ├── Controllers/
│   ├── Models/
│   └── Services/
├── frontend/
│   └── src/
│       ├── components/
│       ├── pages/
│       └── services/
├── database/
│   ├── migrations/
│   └── scripts/
├── README.md
├── .gitignore
└── .gitattributes
```

## Stack Tecnológico

- **Backend**: C# / .NET
- **Frontend**: React
- **Database**: PostgreSQL
