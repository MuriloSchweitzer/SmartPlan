# SmartPlan Frontend

Interface React + Vite do SmartPlan. A identidade visual, os textos, os estados vazios e a responsividade correspondem à versão web de referência do projeto.

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

Configure `VITE_API_URL` com o endereço público da API, incluindo o sufixo `/api`.
